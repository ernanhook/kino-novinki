# Кино-новинки 🍿

Раз в неделю бот присылает в Telegram новые фильмы, сериалы и сезоны с оценкой от 7.5 на IMDb и Кинопоиске. Каждая новинка приходит отдельной карточкой: постер, оценки, краткий сюжет и где посмотреть в Латвии. Под карточкой кнопки «Кинопоиск», «IMDb» и «Где смотреть».

Что считается новинкой:
- **🎬 Фильм** — впервые вышел в цифре: на стриминге, в онлайн-прокате или в продаже. Именно тогда он становится доступен в хорошем качестве.
- **📺 Новый сериал** — премьера первого сезона.
- **🆕 Новый сезон** — премьера второго и следующих сезонов.

У свежих релизов оценки набираются не сразу. Поэтому бот 45 дней (настройка `lookback_days`) каждую неделю перепроверяет новинки и присылает фильм, как только он наберёт 7.5 и достаточно голосов. Одна и та же новинка приходит один раз.

## Советы по запросу 🎯
Напишите боту, что хотите посмотреть, и он подберёт новинки за последние полгода с оценкой от 7.0 под ваш вкус. К каждой карточке прилагается объяснение, почему фильм должен вам понравиться.
- В личной переписке с ботом можно писать просто текстом: «хочу ужастик», «лёгкую комедию на вечер», «сериал про расследование».
- В группе используйте команду: `/kino ужастик`. Чтобы бот понимал и «хочу …» без команды, отключите ему privacy mode: @BotFather → `/setprivacy` → Disable.
- Отвечать в личке бот будет только участникам группы из `TELEGRAM_CHAT_ID`, чтобы чужие люди не тратили лимиты.
- Ответ приходит в течение 15–30 минут: бот запускается раз в 15 минут, а GitHub иногда запускает с опозданием.

**Ваш вкус** берётся из двух мест:
1. `taste.txt` — результат опроса на 100 фильмов и сериалов. Пройдите опрос на странице «Мой кинопрофиль», скачайте `taste.txt` и замените им файл в репозитории.
2. Ваши 👍/👎 на любых карточках бота. Ответьте на карточку «👍» или «👎», и бот поставит 👌, когда учтёт оценку. Если сделать бота администратором группы, можно просто ставить реакции.

Уже оценённые фильмы бот не советует. Запрос понимает и подбирает под вкус Claude Haiku (ключ `ANTHROPIC_API_KEY`), один запрос стоит доли цента. Без ключа бот поймёт основные жанры и посоветует самое высоко оценённое.

Еженедельная подборка ИИ не использует. Ключи TMDB, Кинопоиска и OMDb бесплатные.

## Файлы
| Файл | Что в нём | Менять? |
|---|---|---|
| `settings.txt` | день и час, что включать, пороги оценок, жанры-исключения, страна, советы | да |
| `taste.txt` | ваш вкус: результат опроса | замените своим |
| `main.py` | сам скрипт | не нужно |
| `.github/workflows/digest.yml` | расписание запуска (каждые 15 минут) | не нужно |
| `state.json` | память бота: что уже присылали и оценки; создаётся сам | нет |

## Быстрый старт
1. **Telegram:** @BotFather → `/newbot` → токен. Создайте группу (или канал), добавьте туда бота. chat_id видно в `https://api.telegram.org/bot<ТОКЕН>/getUpdates` после любого сообщения в группе.
2. **TMDB:** зарегистрируйтесь на themoviedb.org → Settings → API → запросите ключ (личное некоммерческое использование). Подойдёт и «API Key», и «API Read Access Token».
3. **Кинопоиск:** получите бесплатный токен неофициального API на poiskkino.dev (бывший kinopoisk.dev). Бесплатно — 200 запросов в сутки, боту хватает.
4. **OMDb (по желанию):** omdbapi.com → API Key → Free. Даёт более свежую оценку IMDb; без него бот берёт оценку IMDb из данных Кинопоиска.
5. **GitHub:** новый репозиторий → загрузить все файлы (вместе с папкой `.github`) → Settings → Secrets and variables → Actions → секреты `TMDB_API_KEY`, `KINOPOISK_API_KEY`, `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID`, для советов — `ANTHROPIC_API_KEY` (можно тот же, что у афиши) и при желании `OMDB_API_KEY`.
6. **Actions → Kino novinki digest → Run workflow** — первая подборка придёт сразу. Она будет больше обычной: в неё попадёт всё подходящее за последние 45 дней.

## Если что-то не так
- **Не пришло ничего** — откройте Actions → последний запуск → шаг `python main.py`: там видно, сколько нашлось кандидатов и какие были ошибки.
- **Слишком много или мало** — поменяйте пороги в `settings.txt` (`min_imdb`, `min_kp`, `min_imdb_votes`, `min_kp_votes`) или `require = any`, чтобы хватало одной оценки.
- **Ошибка «ключ не подходит»** — проверьте секрет в GitHub: без пробелов и кавычек.

## Источники данных
Этот продукт использует TMDB API, но не одобрен и не сертифицирован TMDB. Данные о том, где смотреть, TMDB получает от JustWatch. Оценки — Кинопоиск (через poiskkino.dev) и IMDb (через Кинопоиск или OMDb).
